# دليل الطالب للاستخدام (Student Guide)

أهلاً بك في منصة **كود جيرني أكاديمي** لتعليم البرمجة لطلاب الصف الأول والثاني الثانوي!

## 1. إنشاء حساب وتأكيد الاشتراك
1. افتح صفحة **انشاء حساب طالب جديد** وادخل اسمك بالكامل ورقم هاتفك والصف الدراسي.
2. اختر الكورس المطلوب (مثل: البرمجة والذكاء الاصطناعي - الصف الأول الثانوي).
3. قم بتحويل قيمة الاشتراك (180 ج.م) عبر **انستا باي (InstaPay)** أو **فودافون كاش** إلى الرقم: `01001340533`.
4. ارفع صورة الإيصال في صفحة **المدفوعات** واضغط إرسال.

## 2. متابعة الدروس والتطبيق العملي
- عند دخولك للدرس، يمكنك التنقل بين:
  - **فيديو الدرس**: مشاهدة شرح الفيديو.
  - **الشرح النظري**: قراءة المفاهيم والتعليمات.
  - **محرر الكود والتحدي**: كتابة كود Python بنفسك وتجربته بالضغط على **تشغيل (Run)** أو **تسليم (Submit)**.
  - **كويز الدرس**: حل الأسئلة التفاعلية وتأكيد نسبة النجاح (70%).

## 3. فتح الدرس التالي تلقائياً
سيفتح الدرس التالي تلقائياً فور استكمال شروط المشاهدة والنظري واجتياز الكويز.
